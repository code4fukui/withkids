# WithKids (ウィズキッズ)

[WithKids](https://code4fukui.github.io/withkids/) は、福井県池田町で楽しめる子ども向けのアクティビティを探すためのアプリです。年齢層に合わせて地元の観光スポットや施設を絞り込むことができます。

メイン画面では、アクティビティの一覧が折りたたみ式カードとして表示されます。サイドナビゲーションメニューから年齢別の絞り込みができ、インタラクティブな地図上で周辺のスポットを確認できます。

## 機能
- **年齢別の絞り込み:** 特定の年齢層（0〜3歳、4〜10歳、11歳以上）に応じたアクティビティを提案します。
- **インタラクティブマップ:** 「今どこ?池田マップ」では、以下のような様々なスポットを表示します：
    - 観光スポット & 自動販売機
    - ガソリンスタンド & バス停
    - 公衆トイレ、AED、WiFiホットスポット
    - 緊急施設
- **オープンデータの連携:** `odp.jig.jp` のエンドポイントにSPARQLクエリを送信して位置情報を取得します。
- **Googleマップ連携:** 静的マップのプレビューや、ルート案内用のGoogleマップへのリンクを提供します。
- **レスポンシブデザイン:** Materialize CSSを使用して構築されたモバイルファーストなインターフェースにより、デスクトップとモバイル端末の両方で動作します。

## 技術スタック
- **フロントエンド:** HTML5, CSS3, JavaScript
- **フレームワーク/ライブラリ:**
    - [jQuery](https://jquery.com/) (v2.1.1 & v3.1.1)
    - [Materialize](http://materializecss.com/) (v0.97.7)
- **API & データソース:**
    - **Google Maps JavaScript API:** インタラクティブマップ、静的マップ生成、ルート案内を提供します。
    - **SPARQLエンドポイント:** `https://sparql.odp.jig.jp` に対してクエリを実行し、公共施設や周辺スポットのオープンデータを取得します。

## はじめに
1. リポジトリをクローンします。
    ```bash
    git clone https://github.com/code4fukui/withkids.git
    ```
2. Google Maps APIキーが必要です。本プロジェクトでは `js/main.js` および `map/index.html` にハードコードされたキーを使用しています。
3. ローカルのWebサーバーを使用してプロジェクトファイルを配信します。
4. `index.html` を開くとメインアプリが表示されます。地図は `/map/` からアクセスできます。
